# OpenCode Agent Workflow

Antes de alterar:

- Ler estrutura do projeto.
- Identificar arquivos relevantes.
- Criar plano curto.
- Fazer alterações pequenas e verificáveis.

Durante:

- Não apagar código sem necessidade.
- Não criar backend Next.js.
- Não duplicar componentes.
- Não usar dados fake como solução final.
- Manter TypeScript limpo.

Depois:

- Rodar pnpm check, pnpm lint, pnpm build quando possível.
- Informar arquivos alterados.
- Informar pendências reais.
