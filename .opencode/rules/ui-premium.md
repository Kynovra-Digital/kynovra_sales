# UI Premium

O layout deve seguir Command Center SaaS Layout.

Desktop:

- sidebar fixa
- topbar fixa
- workspace principal
- painéis internos com scroll próprio

Tablet:

- sidebar em drawer
- detalhes em drawer

Mobile:

- app-shell mobile
- cards no lugar de tabelas
- chat fullscreen
- ações em bottom sheet

Regras:

- sem duplicação de cards
- sem scroll horizontal global
- sem página longa estilo site administrativo comum
- labels visíveis em todos os campos
- componentes compactos e premium
